# Request-log write is synchronous: a stalled journal could hold control-plane workers (@79mupg4t)
kind: debt
tags: review-deferred
created: 2026-10-12T21:08Z

- 2026-10-12T21:09Z Codex hostile pass on bakobo/witness#34 reproduced it: with stderr blocked, a real app GET completed only after the write was released, so four stalled requests would occupy all four default waitress workers, health included. Accepted in @79mupg4t on 2026-10-12 because the writer is the control-plane process (separate from the witness loop, @k3p7wr) and journal backpressure reaching the container's stderr through docker's foreground attach was never observed. Trigger to act: any observed stall, or the healthcheck failing while the witness loop is healthy. The fix then is a bounded queue drained by one writer thread that drops lines when full.
